# 行程プランナー

行きたい場所と時間を普段のことばで書くと、スマホの現在地と自分の移動のくせ（歩く速さ、乗換に見込む時間、好きな手段、避けたいこと）に合わせて、経路と出発時刻を逆算したタイムスケジュールを作るWebアプリです。ホーム画面に追加すると、アプリのように使えます。

## しくみ

- 画面（`public/`）：入力欄、現在地ボタン、個人設定、結果の時刻表。個人設定と合言葉はその端末にだけ保存されます。
- サーバー（`src/`）：Cloudflare Workers で動きます。現在地の座標を OpenStreetMap でおおまかな住所にし、Claude（`claude-opus-5-5`）に Web 検索で時刻表や乗換を調べさせながら経路を作ります。
- 合言葉：URLを知った他人に使われて料金がかからないよう、設定した合言葉を知っている人だけが使えます。

## 公開に必要なもの

| もの | 料金 |
|---|---|
| GitHub アカウント（このファイルの置き場所） | 無料 |
| Cloudflare アカウント（アプリを動かす場所） | 無料枠で足ります |
| Claude API キー（console.anthropic.com で発行） | 使った分だけ。1回の経路づくりで数十円ほどの見込み |

## 公開の手順

1. Cloudflare のダッシュボードで「Workers & Pages」→「作成」→「リポジトリをインポート」から、このリポジトリを選んで作成します（ビルドの設定は既定のままで動きます）。
2. 作成したアプリの「設定」→「変数とシークレット」に、次の2つを「シークレット」として追加します。
   - `ANTHROPIC_API_KEY`：Claude API キー
   - `APP_PASSCODE`：好きな合言葉
3. 表示されたアドレス（`https://route-planner.＜名前＞.workers.dev`）をスマホで開き、「あなたの移動のくせ」の合言葉欄に同じ合言葉を入れます。
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」。

## 手元で動かす（開発者向け）

```bash
npm install
cp .dev.vars.example .dev.vars   # キーと合言葉を書き込む
npm run dev
```
